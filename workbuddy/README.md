# RE8CH Qwen Tenant Expert for WorkBuddy

In WorkBuddy open **Plugins → MCP Servers → Configure MCP**, create a remote
Streamable HTTP connector named `RE8CH Qwen Tenant`, and use:

`https://tools.re8ch.com/tenant/mcp`

Complete OAuth with the Qwen tenant identity, trust the connector, and refresh
tools. The Expert instruction is in [`expert.md`](expert.md). Do not embed a
bearer token in WorkBuddy configuration.
