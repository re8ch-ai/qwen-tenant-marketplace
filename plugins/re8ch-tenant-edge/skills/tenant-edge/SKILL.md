# Tenant Edge

Use only `re8ch-qwen-edge`. Qwen owns `ynzs.com`, DNS publication, PublicEdge
candidate selection, and tenant route policy. RE8CH only supplies opaque origin
references. Preview every binding and mutate only Qwen-owned service bindings
after explicit user intent. Never change DNS zones, certificates, other tenants,
provider routing algorithms, or raw network infrastructure.
